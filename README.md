# music-streaming-user-analysis
Müzik platformu kullanıcı veri seti üzerinden dinleme alışkanlıkları, kullanıcı etkileşimleri ve segmentasyon analizlerini içeren kapsamlı projedir. Veri seti kapsamında kullanıcıların günlük dinleme süreleri, abonelik türleri, müzik türü tercihleri ve skip oranları incelenmiş; veri tabanlı 5 gözlem, 3 problem tanımı ve 2 hipotez geliştirilmiştir.
